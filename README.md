# AIFIOK University Portal

An AI-powered University Management System built with Django and PostgreSQL, inspired by the simplicity and professionalism of the WorldQuant University Portal.

---

## Features

### Student Portal
- Student Dashboard
- Course Registration
- Attendance
- Results
- GPA & CGPA
- Transcript
- Academic Progress

### Lecturer Portal
- Course Allocation
- Attendance Management
- Assessment Upload
- Result Upload
- Student Performance Analytics

### Administration
- Colleges
- Departments
- Programmes
- Courses
- Academic Sessions
- Semesters

### Assessment System
- GWP
- CRT
- Test 1
- Test 2
- Test 3
- Project 1
- Project 2
- Project 3
- Final Examination

### AI Features
- AI Academic Assistant
- NLP-powered Search
- Assignment Intelligence
- Student Performance Prediction
- Smart Notifications

### Attendance
- 8-character secure attendance code
- Automatic expiration after 10 seconds
- One-time attendance submission
- Anti-sharing protection
- Lecturer-controlled sessions
